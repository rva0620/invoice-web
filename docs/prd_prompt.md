# 🎯 Invoice Web MVP PRD 메타 프롬프트

> **목적**: 노션에 입력한 견적서 내용을 클라이언트가 웹으로 확인하고 PDF로 다운로드받을 수 있는 MVP 기능을 정의하는 PRD 문서 작성

---

## 📋 프롬프트 (Claude에 복사하여 사용)

```
당신은 Next.js 기반 웹 애플리케이션의 PRD(Product Requirements Document) 작성 전문가입니다.

## 프로젝트 컨텍스트
- **프로젝트명**: Invoice Web (견적서/청구서 관리 시스템)
- **기술 스택**: Next.js 15.5.3, React 19, TypeScript, TailwindCSS v4, shadcn/ui
- **개발 환경**: App Router, Server Actions, Zod 검증, React Hook Form
- **UI 라이브러리**: Radix UI + Lucide Icons

## 🎯 핵심 기능 (MVP Scope)

### 1. 견적서 조회 (Web Display)
- 노션에 입력된 견적서 데이터를 웹 페이지에서 표시
- 클라이언트가 최신 견적서 정보를 실시간으로 확인 가능
- 반응형 디자인으로 데스크톱/모바일 모두 지원

### 2. PDF 다운로드
- 브라우저에서 직접 PDF로 변환 및 다운로드
- 전문적인 레이아웃과 브랜딩 적용
- 인쇄 최적화된 스타일

### 3. 기본 보안
- 견적서 조회 권한 관리 (기본 인증)
- 클라이언트별 접근 제어

## 📊 사용자 시나리오

### 주요 사용자
- **기업 담당자**: 노션에서 견적서 작성
- **클라이언트**: 웹에서 견적서 조회 및 PDF 다운로드

### 시나리오 1: 견적서 조회
```
1. 클라이언트가 공유받은 URL 접속
2. 인증 (필요시)
3. 견적서 상세 정보 확인
4. PDF 다운로드 버튼 클릭
5. PDF 파일 다운로드 완료
```

### 시나리오 2: 견적서 업데이트
```
1. 노션에서 견적서 정보 수정
2. 웹 페이지 새로고침
3. 최신 견적서 내용 확인
```

## 📝 API 설계 (초안)

### 조회 API
```
GET /api/invoices/:id
- 파라미터: invoice_id, auth_token
- 응답: 견적서 데이터 (JSON)
```

### PDF 생성 API
```
POST /api/invoices/:id/pdf
- 파라미터: invoice_id, auth_token
- 응답: PDF 파일 또는 다운로드 링크
